# Photos — how to add your own

The site currently uses **placeholder images** (soft gradients) so it looks
polished before your real photographs are added. Every placeholder lives in
this folder. To use your own photos, simply **overwrite each file with your
photo, keeping the same file name**.

> 💡 Browsers display JPEG, PNG and WebP images regardless of the `.png`
> extension. So you can save/rename your photo to (for example)
> `hero.png` and overwrite the placeholder — it will display correctly with
> no code changes needed. (If you prefer, you can also save real `.jpg`
> files and update the matching `src="..."` references in the HTML — but
> overwriting is the easy route.)

## Tips for fast, SEO-friendly photos
1. **Resize** to roughly the sizes above before uploading (no need for huge
   camera-resolution files — they slow the page down).
2. **Compress** with a free tool such as [Squoosh](https://squoosh.app) or
   [TinyPNG](https://tinypng.com). Aim for under ~200 KB each.
3. **WebP** format gives the smallest files and is supported everywhere.
4. Keep the **descriptive `alt` text** already written in the HTML — it helps
   both accessibility and Google image search. Update it if a photo's content
   changes.

The placeholders were generated by `tools/gen_placeholders.py`. You can delete
that script (and this note) once your own photos are in place.
